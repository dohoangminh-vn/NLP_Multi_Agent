## Đáp án 28.10

28.10. Có lỗi. Có thể sửa cho hết lỗi theo nhiều cách. Ví dụ.
Cách 1. Đưa n vào hàm số khi khai báo hàm f().
```python
def f(n):
    n = n + 1
    return n
n = 15
a = f(n)
print(a)
```
Cách 2. Khai báo biến n là global trong hàm f().
```python
def f():
    global n
    n = n + 1
    return n
n = 15
a = f()
print(a)
```

## Đáp án 28.11

28.11. Chương trình có thể viết như sau:
```python
def Select(A,x):
    B = []
    for k in range(len(A)):
        if A[k] >= x:
            B.append(A[k])
    return B
```
