Hướng dẫn. Gọi S là xâu kết quả sau khi gộp hai xâu s1 và s2, chương trình có thể như sau:

```python
def merge_str(s1, s2):
    S = ""
    l1 = len(s1)
    l2 = len(s2)
    l = min(l1, l2)
    for i in range(l):
        S = S + s1[i] + s2[i]
    if l1 < l2:
        for i in range(l,l2):
            S = S + s2[i]
    if l2 < l1:
        for i in range(l,l1):
            S = S + s1[i]
    return S
```
