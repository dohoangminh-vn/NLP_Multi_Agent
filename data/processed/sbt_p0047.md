22.3. Cho A là danh sách được xác định như sau: A = [1, –2, –3.5, 4, 6, –2.5]. Em hãy cho biết kết quả thực hiện các câu lệnh sau:
a)
```python
s = 0
for i in range(len(A)):
    if A[i] > 0:
        s = s +A[i]
print(s)
```
b)
```python
for i in range(len(A)):
    A[i] = A[i] + 3
```
c)
```python
k = 0
for i in range(1, 4):
    if A[i] < 0:
        k = k +1
print(k)
```
