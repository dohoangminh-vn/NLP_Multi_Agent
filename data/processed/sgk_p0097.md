```python
Chu vi hình tròn là: .....
Diện tích hình tròn là: ....
```

Hướng dẫn. Soạn thảo chương trình sau trong môi trường lập trình Python:

```python
R = 4.5
pi = 3.14
print("Chu vi hình tròn là:",2*R*pi)
print("Diện tích hình tròn là:",pi*R*R)
```
