28.1. Đoạn chương trình sau có lỗi không? Nếu không kết quả lệnh print() sẽ in ra số nào?
```python
def f(x,y):
    n = x + y
    m = x - y
    return 2*n*(m+1)
n = 5
m = 3
f(2,1)
print(n, m)
```

## Bài tập 28.2

28.2. Đoạn chương trình sau có lỗi không? Nếu không kết quả lệnh print() sẽ in ra số nào?
```python
def f(a):
    n = a + 1
    n = (3*n+1)**2
    return n
f(1)
print(n)
```
