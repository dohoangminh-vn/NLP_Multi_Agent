## Đáp án 27.12

27.12. Chương trình có thể viết như sau:
```python
def bmi(m,h):
    return m/(h*h)
ten = input("Nhập họ tên: ")
mass = float(input("Nhập cân nặng: "))
h = float(input("Nhập chiều cao: "))
if bmi(mass,h) < 18:
    print(ten,"Bạn gầy")
elif bmi(mass,h) < 25:
    print(ten,"Bạn bình thường")
else:
    print(ten,"Bạn bị béo phì")
```
